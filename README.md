# AI Building Planner

AI-powered building planning system that analyzes plot dimensions, asks intelligent questions about the user's requirements, applies location-specific building regulations, and generates optimized architectural floor plans with CAD/DXF output.

## Vision

The goal of this project is to build an AI architectural planning assistant that can:

- Analyze plot dimensions and shape
- Understand road direction and site orientation
- Ask intelligent, adaptive questions
- Suggest suitable room arrangements based on the plot
- Identify the applicable building authority and regulations
- Apply building rules and planning constraints
- Check whether the requested requirements are feasible
- Generate optimized floor-plan layouts
- Generate dimensioned CAD/DXF drawings
- Support future DWG and AutoCAD integration
- Allow users to modify designs through natural-language instructions

## Planned Architecture

User Input
→ AI Requirement Interview
→ Location & Jurisdiction Detection
→ Building Regulation Engine
→ Feasibility Analysis
→ Space Planning Engine
→ Geometry Engine
→ CAD/DXF Generator
→ AutoCAD/DWG Integration

## Initial MVP

The first prototype will focus on:

- Residential buildings
- Rectangular plots
- Karachi, Pakistan
- Plot dimensions
- Adaptive AI questioning
- Building-rule validation
- 2D floor-plan generation
- DXF/PDF output

## Future Features

- Multiple cities and jurisdictions
- Commercial buildings
- Plazas
- Apartments
- Electrical layouts
- Plumbing layouts
- Preliminary structural planning
- 3D visualization
- AutoCAD integration
- Professional architect/engineer workflow
- Project and revision management

## Important Principle

AI-generated designs must be validated against structured building rules and geometric constraints. The AI must not invent building regulations or blindly generate a design that violates known constraints.
